# Setup Guide\n\n## Quick Start\n\n### 1. Install Python Dependencies\n```bash\npip install -r requirements.txt\n```\n\n### 2. Install Tesseract OCR\n\n**Windows:**\n- Download: https://github.com/UB-Mannheim/tesseract/wiki\n- Run installer\n\n**macOS:**\n```bash\nbrew install tesseract\n```\n\n**Linux:**\n```bash\nsudo apt-get install tesseract-ocr\n```\n\n### 3. Configure\n```bash\ncp .env.example .env\n# Edit .env with your Instagram username and Facebook page\n```\n\n### 4. Run\n```bash\npython main.py\n```\n\n## Configuration\n\nEdit `.env`:\n\n```bash\n# Instagram\nINSTAGRAM_USERNAME=dhakachronicles\n\n# Facebook (optional)\nFACEBOOK_PAGE_URL=https://www.facebook.com/your-page\n\n# OCR\nEXTRACT_TEXT_FROM_IMAGES=true\n\n# Schedule\nSCHEDULE_INTERVAL_HOURS=1\n```\n\n## Troubleshooting\n\n### Tesseract not found\nSet in `.env`:\n```\nTESSERACT_PATH=C:\\Program Files\\Tesseract-OCR\\tesseract.exe\n```\n\n### No posts extracted\n- Verify username/URL\n- Profiles must be public\n- Check logs: `tail -f logs/automation.log`\n\n## Viewing Results\n\n```bash\n# Logs\ntail -f logs/automation.log\n\n# Database\nsqlite3 data/news_posts.db\nSELECT * FROM news_posts LIMIT 5;\n\n# Images\nls data/images/\n```\n
